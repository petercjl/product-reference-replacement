# 独立图片与多宫格资产

## 计划与生成边界

先完成A0跨图形态核对及必要的用户基准确认，再选模板，确定n、各格职责/标签、固定box、独立图目标宽高、ratio、resolution及有序原始参考。全貌与尺度必备；整体16:9不要求每格16:9。为每格选择与box内容区相近的受支持比例，留短标签和细间隔，独立图尺寸应足以覆盖放置尺寸。CLI检查计划比例、格位、角色和≥90%覆盖。需要备选时，按素材支持的构图提供少量有序layout_candidates，由board plan在最多16个候选中选择首个合格方案。技术门槛满足且视觉职责可实现后进入A2；进一步调整应对应可定位的商品占比、完整轮廓、参照关系或清晰度问题。照片矩形覆盖与商品本身的可读性分别核对。图片源背景也计入照片矩形，Agent另看主体是否充分占画面。

目标宽高是原件最低验收尺寸；向模型提交ratio与resolution，不提交能力未支持的精确像素要求。若模型实际尺寸低于目标，选择支持的更高档位或在生成前修订规划；不靠放大通过。规划不等于付费请求，真实生成范围与max_requests必须有用户授权证据。

## 原素材选择与保留

每格先读取A0基准和各来源职责，再选用户资料中最直接支持该职责的主素材。保留可用照片中的人物、服装、动作、环境、道具及相对关系，单张生成集中处理必要的画幅整理、清晰化、商品校准或用户指定改动。已有真实人物参照时沿用同一个人物；用户明确要求更换才新增人物或场景。缺素材时先说明缺口或向用户补图。

在plan.panels[].evidence.note记录主素材、保留范围、必要修改和辅助参考职责。参考顺序服从当前明确的职责：通常人物/使用主素材在前，商品参考在后；产品几何校准为重点时，用户指定的正确全貌可置首位。原素材只约束本格明确保留的人物、动作、背景等内容，商品形态以A0确定的原始基准为独立依据，冲突主素材只约束明确保留的人物/场景；如使用生成全貌辅助参考，须核对它仍符合原始基准。应用整体旋转与等比缩放适配场景，保持其结构、内外轮廓、曲率及比例。商品参考不能隐含改换原有人物或背景。相对尺度由原图人物/道具、原有接触锚点和可核实资料共同判断，未确认的人物身高或年龄不作为重新构造尺度的依据；尺寸文字、视觉参照及生成示意分开标注。

## 单图提示词

每次只生成该格的一张高清图片，提示词先交代主素材和保留范围，再描述必要的产品修正、画幅、清晰度与本格用途。原图已明确的人物、家具、布局和光线交给参考图承载；需要改变的部分才写成新要求。全貌保完整轮廓，尺度图保商品和可辨参照的关系，细节图近摄呈现指定证据。商品身份交给原始参考图及简短关系锁定：所有可见结构、比例、组件位置、材质、颜色、文字、标识及连接关系遵循参考。识别笔记单独保存；不把长篇结构描述送入生成提示词。标签由合成器绘制，独立图保留干净画面。缺乏商品视角证据时先补参考，合成图和其他生成图不能代替真实产品证据。

## 顺序、验收和修订

board plan → panel prepare → 媒体dry-run/单次submit → panel attach/同task跟踪下载 → 实际看图 → panel review。然后才到下一格。identity同时对照A0原始基准与通过的全貌核对同款同色、内外轮廓/曲率/比例，并核对所保留人物一致；role核原有服装/动作/环境/道具及接触关系、该格用途和完整轮廓/尺度，clarity核原件与关键局部。只有三项PASS且尺寸比例合格才选中。技术失败、下载失败和未知提交先恢复相同任务，预算按prepare预留；未完成记录保持阻塞，不能用新请求代替恢复。

用户或验收指出某格问题时，用panel_id、原因及新完整提示词创建本格下一revision。使用该格原始参考，保留其余格通过版本。请求预算用尽就汇报并等待追加范围；A的沟通不是B每图四轮规则。历史通过图不会被新失败图覆盖；有未通过最新修订时暂不交付新的完整整板。

## 合成与交付

全部最新单图通过后board compose，按锁定box等比拼合，保存images目录中的n张未缩放原件、board子目录中的16:9整板和两个预览、composition.json中的版本/来源/hash及请求验收证据。单格修订只变该格图源，其他格不重新生成、不重排，结果像素应保持一致。整板还需board check和真实视觉review，用户满意再freeze。单图技术通过不能代替用户定稿；新合成不继承旧整板的用户满意声明。

已有直接裁片计划可以用board render读取、复现；新建资产主线使用独立单张生成。用户明确只要原图拼合时，按该具体范围本地渲染并说明交付为原图整理。
