# 资产复用、场景任务与验收

已有资产可直接B：看同款身份、结构/纹理可辨性与覆盖边界；不强制原始资料、不自动重做板。固定一个asset版本和hash供整组引用。默认single只选一张；用户明确batch后登记整组并按顺序逐项执行。批量不等于多候选或并发。

每图单独看：产品位置、视角、尺度证据、接触遮挡、人物姿势、机位、背景、构图、光线和需保留文字。商品外形由资产板决定，场景尺度依据已有可靠关系，不机械复制旧产品形状。

提示词示意：将图1指定位置产品替换为图2资产板所示同款。图1提供人物、场景、构图与光线，图2提供产品身份；全部可见结构、比例、组件关系、材质、颜色和标识遵循图2。保持原场景关系，接触、遮挡和投影自然，输出一张完整场景。

两道独立门：
1. 商品门：对比资产板和有条件可用的原始来源，检查轮廓、比例、组件拓扑、材质纹理、款色和标识。一个确认的关键变化即FAIL，不以好看抵消。
2. 场景门：对比该图原始场景，检查人物/手、位置、遮挡、机位、背景、光线、构图和文字。产品正确而人物重排仍不通过。

每项判定PASS/FAIL/UNCERTAIN/ANCHOR_CONFLICT，记录位置与原参考证据；区分透视、光照、遮挡造成的表观差别，真实不确定不虚构为缺陷。可见证据不足不能判PASS。

两门PASS结束；FAIL且有预算则根据主要偏差改完整提示词，用原始两图再生成1张；每图含首轮最多4轮。后续图片可复用商品锁定原则，但不能盲抄别图机位指令。

冻结资产改变则暂停并报告；需新版本时确认影响范围，已有轮数保留、通过项不自动重做。恢复未知结果沿用task_id，技术失败不自动新增付费任务。整批预算和单图4轮分别管理。
