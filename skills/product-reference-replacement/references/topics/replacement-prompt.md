# 双参考替换提示词编译

触发：B2，蓝图ready后。问题：哪些文字是参考图无法直接表达、却会决定替换结果的必要约束？输入为原始双图、蓝图与本轮主要失败原因；输出为本轮完整提示词文件；回B2准备请求。

## 六组内容，按需要合并成简洁指令

1. **任务与角色**：明确替换目标范围。图1负责原场景，图2只负责商品身份；辅助人物、标签和背景不迁入场景。
2. **身份锁定**：全部可见商品结构、比例、组件位置与连接关系、材质、颜色、文字和标识遵循资产；不增删、移动或重新设计组件。
3. **场景保护**：按蓝图保护人物身份、姿态、可见范围、背景、文字、构图和机位。原图已经清楚的内容不逐件重复描述。
4. **放置关系**：仅补充有必要明确的支撑/握持锚点、相对尺度和整体朝向；以参考为依据，不给缺乏证据的精确数值。
5. **接触与遮挡**：表达作用方式、前后关系和手部可见范围；软材接触压缩与刚性部件区别处理。只有明确授权时允许接触区轻微手指适配。
6. **光影与输出**：匹配原场景光向、接触阴影、清晰度和构图，输出一张完整场景。画幅与分辨率通过当前模型实际支持参数传递。

## 方法模板

> 以图1为待编辑场景，将其中[选定目标及范围]替换为图2资产中的目标商品。图1控制人物、姿态、机位、背景、文字与原光照；图2控制商品身份，全部可见结构、比例、组件关系、材质、颜色与标识遵循图2。保留[保护对象和可见范围]，按[锚点、相对尺度和整体朝向]放置商品，保持[接触与前后遮挡]，匹配接触边缘与原场景光影。输出一张完整场景图片。

这是编译方法，不是每次照抄全部字段的固定咒语。方括号需落实为当前场景关系；参考中已经清楚的事实可省去重复句。商品识别笔记、细节清单、候选分析、费用与任务状态留在记录中。避免用长篇结构描述重建商品，也不追加无关8K、散景、渲染或风格词。

## 迭代编译

对比原场景、资产与当前结果，选择最主要的失败层：身份、几何尺度、接触/遮挡、背景文字或光影。先核实它是实质偏差，还是透视、照明、压缩的合理表观变化。若蓝图错，先修蓝图；否则围绕问题重写简洁完整提示词，保留仍有效的关系约束。把纠错消化为最终要求，不累计过时否定句或描述完整修改历史。

始终用原场景＋同一资产生成一张；上一轮结果仅用于诊断。通过即停止，每图最多四轮。新方案能否提高首轮通过率仍需真实对照，不能因模板完整就宣称效果已验证。

## 能力边界

当前路线是双参考整图编辑，场景保护通过生成约束与验收实现。运行时核对当前媒体合同；语义区域、包围框或“保留”文字不能代替真实mask、像素合成或指定尺寸能力。若用户要求逐像素一致而当前合同不能提供，报告FEATURE_UNSUPPORTED并说明所缺能力，不承诺纯提示词可冻结像素，也不自行换服务。
