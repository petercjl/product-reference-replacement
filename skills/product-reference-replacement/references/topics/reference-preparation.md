# 从页面资料准备照片参考

触发：A1已确定原始商品基准与本格职责、准备选择参考及比例时。输入是原始资料和本格保留关系；输出是原图或带来源回执的准备照片、实际视觉确认及比例依据；回A1固定规划。只有存在页面装饰或要选照片区时使用准备命令，纯净照片可原样使用。

## 看图选择

先实际看完整来源，区分照片内容与详情页的文字、外框、灰底、留白和拼图装饰。标出真实照片范围，以及本格必须保留的商品、人物、握持/接触、尺度参照和必要场景。商品整体/尺度格须保完整商品；人物证据的范围按本格职责明确，不能裁掉必要的人物或接触关系再声称保留。详情页参数文字等额外证据另存分析，不强行放进照片参考。

裁切坐标按EXIF归正后的原像素确定。页面有圆角时检查四角及边缘，矩形裁切未必能同时移除圆角装饰并保全证据。必要时改用同职责的其他原始照片、保留并说明残余风险，或请求补图；不能把生成重画未知区域当作真实证据。裁切仅选择原始证据，不改变A0已确认的商品形态基准。

## 本地准备与视觉确认

使用reference prepare保存无缩放照片区、原图/照片hash、裁切与保护区域、原图坐标预览及比例建议。脚本只验证像素边界和声明区域是否完整，不能识别人物或自动判断页面。必须实际查看原图、source-preview.png及reference.png，比较边界、完整轮廓、人物、接触及必要环境，填写命令返回的review_template；reference check通过后才把prepared/review引用放进board plan。

照片中有真实白墙、灰色家具等，不以颜色判断页面装饰。无法可靠区分就说明不确定，不做自动阈值删边或内容补齐。准备图片保留原生裁切尺寸；预览的缩小仅供检查。

## 比例与固定格位

先用保留全部必要证据的照片比例，再结合本格用途、固定box及当前模型可用ratio选择相容构图。命令的suggested_ratio只是矩形适配建议，不替Agent决定目标或替媒体声明支持。若选择的比例需过多补画、裁掉主体或产生明显留白，调整格位/其他证据/规划候选，不继续缩裁重要区域来凑框。纯照片输入不强制再次裁切，也不把独立图片或整板统一成同一比例。

生成后仍检查真实原件尺寸、页面残留和白边。前置裁切不能保证没有返工；不得事后裁除生成白边、补边或放大后冒充原始分辨率通过。媒体失败恢复、总预算、逐格串行和用户定稿规则保持主线。
