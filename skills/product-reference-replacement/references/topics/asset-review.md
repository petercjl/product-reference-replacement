# 资产图用户沟通与定稿

每版先实际查看并技术检查，再展示真实图片和简短来源/缺口说明。让用户指出需要改的选图、分区、格数、标签或大小；局部改动只动相应分区并检查依赖。另存计划与输出目录，保留原件和历史版本。

Agent自检通过不等于用户满意。freeze的user_approved与approval_evidence只能来自实际用户消息。用户提供现成资产要求使用则通过import记录provided_for_use，二者意义分开。

用户反馈驱动迭代，不默认凑满次数，也不把B的4轮上限用于本地资产沟通。推荐确定性原图拼合；用户明确选择生成式重绘时复用规定的媒体包和nano-banana-pro模型，明确预算并按原始证据验收。

定稿后先交付可独立使用的16:9文件，再邀请进入修改：是否开始、待改图在哪里、single还是batch。已有场景图时列出它们确认范围，无需再上传。资产满意不自动开始收费任务。

## 检查与真实交付

先board check读取几何指标与必备角色；查看整板、原始裁片及自动输出的1600/1920预览。逐格核对角色、视角标签、同款身份、完整轮廓和参照关系；尺度必须让人理解完整商品的相对大小，手压局部不等于整件尺度。按工具合同记录artifact_sha256、role_verdicts、labels_match、identity_match、reference_clear、previews及evidence，再check。机械覆盖或实际可读性不过，返回A1调整；草稿可如实展示，不能称完整合格资产。

通过检查仍是待用户确认。交付用宿主原生图片预览或绝对路径Markdown图片，并提供绝对文件链接；标签只说明角度/职责。宿主不支持预览时明确说明并给可打开链接。用户满意后，review合并真实批准依据与board_directory供freeze复核。已有外部资产仍按B导入，保持其独立入口。

当前A先逐张生成并验收，整板由board compose合成；交付n张独立原图和整板。用户反馈单格时，按panel_id回A2仅重生该格，再以原box和其余格原件重合成新版本。原件hash和固定格位用于证明其他格未变；每版整板独立等待用户定稿。

对照每格evidence.note验收素材保留范围：原人物的身份、年龄外观、服装、动作、原场景与参照道具应符合规划。商品通过不能掩盖这些对象被擅自更换；有偏离记录在identity/role的FAIL及issues，回A2只修改受影响格。
