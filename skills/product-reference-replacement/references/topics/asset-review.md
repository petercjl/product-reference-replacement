# 资产图用户沟通与定稿

每版先实际查看并技术检查，再展示真实图片和简短来源/缺口说明。让用户指出需要改的选图、分区、格数、标签或大小；局部改动只动相应分区并检查依赖。另存计划与输出目录，保留原件和历史版本。

Agent自检通过不等于用户满意。freeze的user_approved与approval_evidence只能来自实际用户消息。用户提供现成资产要求使用则通过import记录provided_for_use，二者意义分开。

用户反馈驱动迭代，不默认凑满次数，也不把B的4轮上限用于本地资产沟通。推荐确定性原图拼合；用户明确选择生成式重绘时另定模型、预算和原始证据验收。

定稿后先交付可独立使用的16:9文件，再邀请进入修改：是否开始、待改图在哪里、single还是batch。已有场景图时列出它们确认范围，无需再上传。资产满意不自动开始收费任务。
