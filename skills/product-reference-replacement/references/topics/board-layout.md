# 固定16:9布局与完整证据

A1先用通用基线与匹配品类内容模板确定图片职责和最少充分格数，再按[固定布局库](../layouts/README.md)选择layout_id。内容模板与几何模板分别维护；每张独立图绑定一个slot_id，目标比例和分辨率由实际素材及媒体能力确定。

全貌保护完整轮廓，尺度保护商品与足以判断相对关系的人物/常见物；细节紧裁目标区域。每格记录真实观察依据。图片数量依据新增信息确定，建议2–8格。

固定库覆盖2–8格，5格有上二下三与左主右四两种构图。最大格/最小格面积比≤2.5，最小格面积≥9%，全貌格≥22%，尺度格≥14%。1600宽预览的实际照片矩形短边至少300像素。以上是本应用设计门槛，不是行业标准。

用layout list/show读取真实坐标和照片框，运行board check-plan核验全部问题；board plan保存模板编号/版本、内容到slot的映射及固定box。新制作以固定库为入口；旧无layout_id计划保留原始兼容合同，不重排正在运行的项目。合成时保持锁定格位，单格重生仅改变该格图片版本。

照片矩形覆盖率≥90%，短标签与细分隔占少量画布。指标包含照片自身背景，不等于商品主体占比。实际看1600/1920宽预览，核对每个角色的产品身份、完整轮廓、尺度关系与细节；留白过多、文字难读或主体过小，回A1重新选择模板/构图或修订对应单格。用户满意后才freeze。
