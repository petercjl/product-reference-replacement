# 信息覆盖与16:9资产布局

先列完整外形与关键身份信息，再选补充角度、连接细节、表面纹理、标识或使用状态。每新增一格应增加可核验信息。最少充分覆盖优先；3–4格、5–8格只是示例，不作为固定宫格。

主视完整图保留轮廓和比例，细节裁图承担局部可读性；允许大主图加小格。标题如实标“正视全貌”“斜视全貌”“结构细节”“表面纹理”，不把斜视冒称标准正视。不同状态、包装/主体标明角色；仅选目标款色证据。

每格记录source、EXIF归正后的crop、box、label、role；等比缩放、留白、标签放在商品外，不拉伸镜像改色。整体16:9，建议3840×2160，实际信息清晰度取决于源像素；放大不增加真实细节。

先在整板检查信息层级，再放大每格核对原始证据，并在实际参考尺寸检查关键纹理/结构。过密时先去重复或放大关键分区。缺重要视角就列缺口、请求补图；不按想象补成事实。当前素材无法充分覆盖时交代边界，不假称完整。

资产图可脱离具体场景独立制作、定稿和复用。以后B发现某一机位缺关键证据时由用户决定补图或调整资产，不为每张目标重做资产。
