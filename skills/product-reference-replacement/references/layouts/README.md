[机器可读库](library.json)是坐标与版本的唯一来源。coordinate_units=12000，各rect按统一坐标系记录；CLI按画幅缩放相邻边界并取整，保持无重叠和完整铺满。每套模板的版本1几何固定，未来变更发布新版本并保留旧版解释能力。

## 选择与固定

1. 实际看完同款资料并完成A0。按新增识别信息确定2–8张；全貌overall、尺度scale必备。
2. `layout list --json`发现本库；对候选执行 `layout show --layout-id ID --width W --height H --padding P --label-height L --json`。返回固定格位、照片框尺寸、比例适配度和保持对应ratio所需的最低目标尺寸。
3. 根据素材构图匹配：s1放overall，s2放scale，其余格按内容优先级分配；L7/L8的s3为重点补充。slot_id是位置身份，panel id是内容身份。5格先比较L5A和L5B；选择保留完整商品、人物与尺度关系且比例适配更好的方案，记录理由。其他格数有一套基础方案；不适配时提出新模板需求供确认。
4. 根据当前媒体模型实际ratio/resolution能力，选择各格独立生成目标。show中的比例排序只是几何建议；素材职责、完整性及可读性共同决定选择。提示词用构图和参考关系约束，生成每格独立高清图。
5. 计划写layout_id、layout_version:1和每个panel的slot_id；box可省略，由CLI从模板生成。board check-plan返回逐格真实尺寸与问题，通过后board plan锁定。整体模板、格位和参考职责保持到合成；用户局部修改沿用相同格位。

## 几何与可读性门槛

- 最大/最小格面积比≤2.5，单格画幅面积≥9%；比例按格位计算，标签和间隙包含在其中。
- 1600像素宽预览下，实际contain照片矩形短边≥300像素；按每张图的目标比例计算，扣除标签与间隙后验证。高分辨率原件与小格显示面积分别检查。
- 照片矩形覆盖率≥90%，全貌格≥22%，尺度格≥14%。覆盖率包括照片自身背景，实际主体可读性须看图验收。
- 保护全貌、完整尺度关系和必要细节。先选合适构图与模板；放大原件像素、拉伸产品或任意裁掉关键证据不能修复可读性。

以上数值是本应用已确认的设计门槛，非行业标准或模型内部处理分辨率保证。锁定前查看布局与各格职责；合成后查看整板和1600/1920预览。

## 兼容与状态

新制作使用本库的显式layout_id。已有不带layout_id的历史计划、显式box和旧自动布局接口继续按原合同读取和恢复；不在已有项目中重新计算位置。自定义版式作为新增模板的独立规划，不替换当前固定模板坐标。
