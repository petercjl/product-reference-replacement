# 逐张制作资产图片

触发：A1固定分区规划完成、进入A2，或用户要求改某一格。问题：如何只生成一张并保持原始证据、任务恢复和其余格稳定？

读取 [独立图片流程](../topics/panel-generation.md) 和 [依赖合同](../dependencies.md)，工具字段按 [工具合同](../tool-contract.md)。按主素材保留人物、场景与有效关系，商品辅助参考只负责产品校准；记录evidence.note中的保留范围后接管当前panel_id，完成单张准备、媒体任务、实际看图和单图验收后返回A2；全部通过返回A3合成。整板沟通方法到A3才加载，B的蓝图/四轮规则保持延迟。
