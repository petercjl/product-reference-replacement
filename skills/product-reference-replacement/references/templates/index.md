# 产品证据模板索引

进入A1先读[通用基线](generic.md)，识别产品后只加载一个匹配模板；不同子类按实物结构走对应分支。

|template_id|产品|模板|
|---|---|---|
|soft-textiles|抱枕、毛绒、床品、家纺|[软体家纺](soft-textiles.md)|

模板规定证据职责和选图分支；格数与实际角度由原始素材和产品决定。补充角度应提供主视未覆盖的信息。每一格记录源图、款色、裁切、角色与可核查的观察依据。返回A1完成选图，再进入排版；B模式知识保持延迟。
