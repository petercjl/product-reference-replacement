# 方法来源与维护

Coverage: partial。Source classes: W/U/E/A。采用hybrid，商品证据、布局、用户反馈和场景验收在节点按需加载；开发评估位于分发Skill之外。

U：用户确认双模式、默认单张、明确批量、16:9动态宫格、满意后定稿及转场、Nano Banana Pro两图单张替换、每图最多4轮。
W：通用方法“图片工作流：提示词结构与参考控制”“AI生图主体比例与朝向控制方法”“分层能力系统与应用Skill设计规范”。已将参考职责、事实/提示词分离和职责边界内化；运行不依赖私人知识库。
E：当前媒体CLI公开合同与已观察的单张参考编辑、语义切片合同；脚本行为通过本地确定性测试核验。实际底层服务模型身份不由模型请求名证明。
A：最少充分信息覆盖、建议4K资产板、主图大格与细节小格的版式方法。跨品类有效像素和最合适分区数量仍需真实样本；不宣称统计稳定成功率。

重新编译边界：用户修改模式/验收策略，或真实案例暴露可重复的选图、分区、反馈缺口时更新对应方法；服务API变化由媒体能力修复。资料不包含个人素材、任务ID、私有路径或开发标准答案。
