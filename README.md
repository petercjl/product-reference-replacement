# 产品视觉资产与场景替换

一个可供 Codex、SealSeek 及具备命令执行和看图能力的 Agent 使用的应用 Skill。

- 从产品图片或详情页制作可复用的 16:9 产品资产图，与用户沟通调整后定稿。
- 用已有资产图替换单张或明确指定的一组场景图中的产品。
- 替换采用 nano-banana-pro，每次生成一张、检查后调整提示词，每图最多四轮，达标提前结束。

## 安装

把下面这段话发给 Agent：

> 请安装 @petercjl/product-reference-replacement，并将配套 Skill 安装到你当前使用的 Agent。

包包含原图裁切排版、来源追踪和任务记录工具。安装本包不授予生成服务访问权。替换图片需要已配置的 sealseek-media；完整长详情页切片需要 semantic-image-slicer。Agent 会按实际任务检查依赖。

## 使用

制作资产图时附上产品照片或详情页：

> 用产品视觉资产与场景替换，根据所附产品图制作产品资产图。

替换单张时附上资产图和待改图：

> 用产品视觉资产与场景替换，用所附资产图修改这张图片。

批量替换时附上同一产品资产图和待改图片组：

> 用产品视觉资产与场景替换，批量修改这组图片，共用所附资产图。

## 更新和检查

> 请更新 @petercjl/product-reference-replacement 及当前 Agent 中的配套 Skill。

> 请检查 product-reference-replacement 的安装与依赖状态。

普通任务入口会限时检查新版本，默认仅提示。开发者和 Agent 可查看包的机器可读能力合同及命令帮助；自定义宿主使用显式目标目录安装，更新后同步相同目标。

## 验证范围

本地确定性图片处理、任务状态与安装机制有自动化测试。macOS 与 Windows 的包级验证由发布 CI 执行。完整 Agent 会话、收费生成结果及其他平台的实际视觉能力需要分别验收。
